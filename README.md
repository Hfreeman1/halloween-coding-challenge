# Halloween Coding Challenge

This project was created for my Web Programming course.

## Project Description

The Haunted Harvest is a Halloween-themed webpage with three different scenes. The scenes include a haunted town, a spooky graveyard, and a pumpkin patch. The webpage uses HTML and CSS for the layout, navigation, colors, and animations.

## How to View

Open `index.html` in a web browser to view the project.

## Technologies Used

- HTML5
- CSS3
